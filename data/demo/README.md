# Demonstration patient examples

This folder contains 20 anonymous historical examples derived from the public UCI Heart Disease collection for use in the CardioModel Shift interactive interface.

Five records from each binary outcome class were sampled reproducibly from each cohort using random state 42. The file contains only the ten harmonised modelling features, cohort, example identifier and binary recorded-disease label.

The examples are provided solely to demonstrate model behaviour across cohorts. They do not represent current patients and must not be used for personal medical assessment.

Source: Janosi, A., Steinbrunn, W., Pfisterer, M., and Detrano, R. (1989). *Heart Disease*. UCI Machine Learning Repository. https://doi.org/10.24432/C52P4X
